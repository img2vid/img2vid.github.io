<h2 align="center">🎬 <strong>Media & Video Creation</strong></h2>

### 🎥 <strong>img2vid</strong> <sub><i>Bulk Images + Audio to Video Converter</i></sub>
> **🔗 Repository:** <a href="https://img2vid.github.io" target="_blank">img2vid.github.io</a> | **🏷️ Category:** <code>Media Processing</code>

Seamlessly stitch sequentially named image files (e.g., <code>img001.png</code>, <code>img002.png</code>) together with a single audio track to create stunning videos. Perfect for bulk rendering, time-lapses, and automated video pipelines.

<details>
<summary>✨ <strong>Key Features</strong> <i>(Click to expand)</i></summary>
<br>
<ul>
  <li>🔄 <strong>Multi-Job Support:</strong> Queue up multiple conversion jobs simultaneously in the browser.</li>
  <li>⏱️ <strong>Smart Duration Calculation:</strong> Automatically divides the total audio length by the number of images if the duration field is left blank.</li>
  <li>🎥 <strong>Flexible Outputs:</strong> Export your creations in popular formats like <kbd>MP4</kbd> or <kbd>MOV</kbd>.</li>
</ul>
</details>

### ⚡ <strong>FastReader</strong> <sub><i>RSVP Speed Reading Application</i></sub>

A revolutionary speed-reading application that helps users achieve incredible reading velocities. It achieves this by utilizing the <strong>Rapid Serial Visual Presentation (RSVP)</strong> method, eliminating eye-tracking fatigue.
